# Data Release Note

This repository does not include the original administrative records.

The original records were accessed under data-sharing permission and are not publicly released because they may contain enforcement-sensitive information. Before research use, identifiers and sensitive administrative references were removed. The repository releases only research-level files prepared for reproducibility.

The public data files do not include:

- facility names,
- officer identifiers,
- precise location markers,
- administrative case numbers,
- active enforcement references,
- raw administrative case files.

The public files include:

- `rule_library.csv`: machine-readable environmental rule objects,
- `environmental_cases.csv`: de-identified and rule-mapped case attributes,
- `case_outputs.csv`: proof-state references, validation outputs, evidence-chain outputs, and case-file actions,
- `train_ids.csv`, `val_ids.csv`, `test_ids.csv`: fixed split identifiers,
- `data_dictionary.csv`: column definitions and leakage-control status.

The dataset is intended only for academic research. It must not be interpreted as legal advice, official enforcement evidence, or a regulatory decision record.
